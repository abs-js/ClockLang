>clk_ Clock 0.5.0

Documentação da linguagem, runtime e sistema de pacotes. main.py é o coração de tudo.

Início

Execute:

Clock arquivo.clk
Clock -v
Clock -h

Bandeiras do Clock

-v, --version     versão
-h, --help        ajuda
-H, --history     histórico: comando + saída
-u, --unsleepy    ignora sleep()
-a, --autoinstall instala dependências ausentes

Módulos

Import

import Math as m
import Str as s
import Fs as fs

Math e Str são pré-instalados. Fs é instalável.

Fs

set texto as $fs.read("test.txt")
set file as $fs.requestWrith("test.txt")
get $file.addLine("nova linha")
get $file.rmvLine(0)
get $file.mvLine(0, 1)
get $file.finish()

Sistema

set linha as @
set congelada as $linha
get CLASSES.std().print(@)
get sleep(1000)
get die("fim")

@ sempre representa a linha atual. Ao salvar `@` em uma variável, o valor salvo permanece fixo.

DATE

set d as \CLASSES.DATE()\
get CLASSES.std().print($d.day)
get CLASSES.std().print($d.year)
get CLASSES.std().print($d.mth)
get CLASSES.std().print($d.s)
get CLASSES.std().print($d.min)
get CLASSES.std().print($d.h)
get CLASSES.std().print($d.ms)
get CLASSES.std().print($d.wd)

HISTORY

get CLASSES.HISTORY[11]
get CLASSES.HISTORY.START
get CLASSES.HISTORY.PAUSE

O histórico é somente leitura. `get CLASSES.HISTORY[n]` reproduz o comando. Guardar o item numa variável o transforma em string.

EasyTime

Não pré-instalado. Instale:

ClockInstall install EasyTime

Depois:

import EasyTime as time
set agora as $time.get("dd/mm/yy - minmin:hh")
get CLASSES.std().print($agora)

O padrão documentado gera algo como 01/10/26 - 14:25.

ClockInstall

ClockInstall -v
ClockInstall -h
ClockInstall -r install Fs
ClockInstall install EasyTime
ClockInstall uninstall Fs
ClockInstall list
ClockInstall checkConn
ClockInstall searchPack time
ClockInstall -i EasyTime
ClockInstall -d EasyTime

Por padrão o gerenciador consulta abs-js/CPM, branch main, e instala em ClockPacks/NOME.

Para esta versão, a URL pública do repositório foi testada e respondeu 404. A implementação está apontada para ela mesmo assim e emitirá o erro de conexão/HTTP caso o repositório esteja privado, renomeado ou indisponível.
